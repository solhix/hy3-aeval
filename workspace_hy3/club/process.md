# 解题过程：社团招新 (P14363? 注：实为 CSP-S 2025 社团招新)

## 1. 题意理解
n 个学生，每人可在 3 个社团中任选 1 个（或都不选？题目要求每人在恰好一个社团）。每个社团人数不得超过 n/2（向下取整）。每个学生加入不同社团有不同能力值 a[i][0..2]。求能力总和最大值。多组测试。

## 2. 算法思路（修正版）
初版错误：误以为"至少有一个部门恰好 n/2"才最优，忽略了三个部门都可 < n/2（如 6 人分配 (2,2,2)）。修正后枚举三类候选：
- 候选 0：每人选自身能力最大的部门，若某部门超额则在不损失能力（等值且目标部门未满）时让位；最终若各部门≤n/2 则采纳。
- 候选 A：恰好一个部门满 n/2（其余两部门取各自较大值，选 n/2 人进满员部门使总能力最大）。
- 候选 B：恰好两个部门满 n/2（第三部门空，类似处理）。
取三者最大值。

## 3. 复杂度分析
每组 O(n) 或 O(n log n)（nth_element），t 组，满足时限。

## 4. 边界处理
- 各部门人数上限 floor(n/2)。
- 等值让位避免无谓超限。
- 多组 t 循环。

## 5. 关键步骤
1. 读 t、n、a[i][0..2]。
2. 候选 0：贪心选最大部门 + 等值让位。
3. 候选 A/B：固定满员部门组合，nth_element 选最优 n/2 人。
4. 输出 max。
