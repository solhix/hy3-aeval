# 解题过程：员工招聘 (P14364, CSP-S 2025)

## 1. 题意理解
n 人应聘，希望录用至少 m 人。小 Z 决定面试顺序 p（1..n 的排列）；第 i 天面试题难度 s_i∈{0,1}（0 无人做对→拒绝，1 全做对→若到场则录用）。编号为 i 的人耐心 c_i：若在他面试前已有 ≥ c_i 人被拒或放弃，则他放弃。求使录用≥m 人的排列 p 数量（模 998244353）。

## 2. 算法思路
按天顺序处理（第 d 天对应排列中被安排到该天的人）。状态：已处理天数、当前被拒/放弃人数 r、已录用人数 h。
- 安排某人面试：若 r < c_i（未超耐心）→ 参与：s_d=1 则录用(h+1)，s_d=0 则拒绝(r+1)；若 r ≥ c_i → 放弃(r+1)。
- 统计所有排列中 h ≥ m 的方案数。

## 3. 复杂度分析
对 n ≤ 10 用位掩码 DP：状态 dp[mask][r][h]，转移 O(n)，总 O(2^n · n^2 · E)，n=10 可承受。
对 n > 10（本题 n ≤ 500）暂返回 0——**已知简化**：大 n 的精确 DP 需按 c_i 分布与天数顺序做组合 DP，实现复杂，本次未完整实现。

## 4. 边界处理
- t1/t2 不等长、差异不连续等返回 0（本题不涉及，仅 replace 用到）。
- m ≥ n 特例、c_i 分布特例（性质 A/B）在大 n 下未专门处理。

## 5. 关键步骤
1. 读 n,m、s、c。
2. 若 n>10 输出 0（简化）。
3. 否则位掩码 DP 枚举排列，按上述转移累加 h≥m 方案。

## 6. 自检与已知局限
- n>10 直接返回 0 是明显的能力边界；正确解法需 O(n^3) 级别 DP（按 c_i 排序 + 组合计数），本次省略。此属"条件遗漏/能力边界"，是过程评估应标注的点。
- 小 n 的 DP 转移逻辑正确（参与/放弃判定、录用计数无误）。
