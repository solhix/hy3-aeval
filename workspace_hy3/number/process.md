# 解题过程

## 1. 题意理解

从字符串 $s$ 中任意选取数字字符（每个字符最多使用一次），按任意顺序拼接成一个正整数，要求输出能拼成的最大值。$|s| \le 10^6$，$s$ 中保证至少存在一个 $1\sim 9$ 的数字。

## 2. 算法思路

要让拼接结果最大，等价于让高位的数字尽可能大。因此最佳策略是：把所有选出的数字按**降序**排列。

由于题目保证至少有一个 $1\sim 9$ 的数字，所以 $0$ 不会出现在最高位。具体实现：
- 先输出 $9,8,\dots,1$，每个数字输出其出现次数；
- 最后输出所有 $0$。

## 3. 复杂度分析

- **时间复杂度**：$O(|s|)$，只需遍历字符串一次统计每个数字出现次数。
- **空间复杂度**：$O(1)$，仅使用大小为 $10$ 的计数数组。

## 4. 边界处理

- 字符串长度可达 $10^6$，使用 `ios::sync_with_stdio(false); cin.tie(nullptr);` 加速输入。
- 题目保证至少有一个非零数字，避免纯 $0$ 导致的前导零问题。
- 输入中可能混有英文字母，只提取 `'0'\sim'9'`。

## 5. 关键步骤

1. 读入字符串 $s$。
2. 用计数数组 `cnt[10]` 统计每个数字出现次数。
3. 从 $9$ 到 $1$ 依次输出 `cnt[d]` 个该数字。
4. 最后输出 `cnt[0]` 个 $0$。
