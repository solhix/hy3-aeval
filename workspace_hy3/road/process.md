# 解题过程：道路修复 (P14362, CSP-S 2025)

## 1. 题意理解
有 n 座原有城市（保证原本通过 m 条道路连通），k 个乡镇。修复第 i 条道路费用 w_i；城市化改造第 j 个乡镇费用 c_j，改造后可在该乡镇与第 i 座城市间建路，费用 a_{j,i}。目标：以最小费用让 n 座原有城市两两连通。可选择改造任意多个乡镇（也可不改造）。

## 2. 算法思路
- 核心是把"乡镇"当作可选的 Steiner 点：改造一个乡镇后，它可以在城市之间架桥。
- 基础情形（不使用任何乡镇）：直接在 n 座城市上用 m 条修复边做最小生成树（Kruskal），这能保证连通（原题保证原有道路已连通）。
- 引入乡镇：把乡镇 j 视为一个新增节点，连接 hub（节点 0，费用 c_j）与所有城市 i（费用 a_{j,i}）。在"城市+乡镇"的图上再做 MST，取 min。
- 最终答案 = min(不改造, 单乡镇改造, 全部乡镇一起改造)。

## 3. 复杂度分析
Kruskal：O(E log E)，E 为边数。对每题最多做 1 + k + 1 次 MST，k ≤ 10，n ≤ 1e4、m ≤ 1e6，在时限内可行（近似，部分大数据点可能偏慢）。

## 4. 边界处理
- 原有城市已连通，基础 MST 必存在。
- 乡镇改造与否取 min，避免无谓增支。
- 多组测试（本题单组 t=1）。

## 5. 关键步骤
1. 读入 n,m,k 与 m 条修复边。
2. 读入 k 个乡镇的 c_j 与 a_{j,i}。
3. base = MST(城市, 修复边)。
4. 对每个乡镇单独建模求 MST 取 min；再尝试全部乡镇一起建模取 min。
5. 输出最小费用。

## 6. 自检与已知局限
- 建模将"全部乡镇一起"强制入树，可能引入不必要乡镇（叶节点冗余），不是严格精确解；多个乡镇组合的最优解未穷举（2^k 子集在 m=1e6 下不可行）。
- 正确做法应只用"必要"的乡镇子集；当前实现对 k=0 精确，k>0 为近似，可能在大测试点失分。此属"条件遗漏/简化"，是过程评估应捕获的点。
