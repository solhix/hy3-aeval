# 解题过程：谐音替换 (P14363, CSP-S 2025)

## 1. 题意理解
给定 n 个字符串二元组 (s_{i,1}, s_{i,2})（长度相等）。定义对字符串 t 的一次"替换"：选一个子串 y，若存在 i 使 y = s_{i,1}，则把该次出现替换为 s_{i,2}。q 次询问，每次给 t1、t2，问有多少种"替换"（位置不同或所用规则 i 不同即算不同）能把 t1 变成 t2。

## 2. 算法思路
一次替换只改一个子串，且替换前后长度不变（|s_{i,1}|=|s_{i,2}|），故 t1、t2 必等长。
- 替换可发生的唯一位置 pos 必须使：t1[0:pos)==t2[0:pos) 且 t1[pos+len:]==t2[pos+len:]（区间外两串一致），且区间内有 t1 段 == s_{i,1}、t2 段 == s_{i,2}。
- 先求 t1、t2 的最长公共前缀 l 与最长公共后缀（从差异处起）r，差异区间即 [l, r)。
- 一个合法替换段必须覆盖整个差异区间：pos ≤ l 且 pos+len ≥ r，即 pos ∈ [max(0, r-len), l]。
- 对每个规则 i（长度 len），在合法 pos 范围内统计同时满足 t1[pos:pos+len]==s_{i,1} 且 t2[pos:pos+len]==s_{i,2} 的 pos 数，累加。

## 3. 复杂度分析
每询问：求 l、r 为 O(L)；对每条规则扫描 pos 范围并用 string::compare 判定，最坏约 O(n·L)。n,q ≤ 2e5、L ≤ 5e6，极端情形偏慢，可能 TLE；小数据正确。

## 4. 边界处理
- t1、t2 不等长直接 0。
- 若 l > r（差异不连续）直接 0。
- len < r-l 的规则无法覆盖差异，直接跳过。

## 5. 关键步骤
1. 读 n,q 与规则。
2. 对每询问：求 l、r；枚举规则与合法 pos；用 compare 判定并计数。
3. 输出每询问答案。

## 6. 自检与已知局限
- 用朴素比较而非哈希/AC 自动机，大数据点可能超时；属"效率/算法选型"层面局限。
- 逻辑上覆盖"差异必须落在单一替换段内"，对单替换语义正确；若题目允许"多步替换"则模型误读题意（本题明确为单次替换，理解正确）。
