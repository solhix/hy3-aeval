# 解题过程：环形数组最大子段和

## 1. 题意理解
给定一个长度为 n 的数组，求最大子段和。

## 2. 算法思路
用 Kadane 算法：dp[i] = max(a[i], dp[i-1] + a[i])，维护全局最大值即可。遍历一遍数组，每个位置决定是重新开始还是延续前面的子段。

## 3. 复杂度分析
- 时间复杂度：O(n)，只需遍历一遍数组
- 空间复杂度：O(1)，只维护两个变量

## 4. 边界处理
- 全负数组时答案为最大单元素（Kadane 初始化即为 a[0]，自动处理）。

## 5. 关键步骤
1. 初始化 curMax = maxSum = a[0]。
2. 遍历 i=1..n-1，curMax = max(a[i], curMax + a[i])。
3. 更新 maxSum = max(maxSum, curMax)。
4. 输出 maxSum。
