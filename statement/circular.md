# 环形数组最大子段和

## 题目描述

给定一个长度为 n 的环形整数数组 nums，返回数组中可能的**最大非空子段和**。

环形数组意味着数组的末端会连接到开头，子段可以跨越数组首尾。形式上：
- nums[i] 的下一个元素是 nums[(i+1) % n]
- nums[i] 的前一个元素是 nums[(i-1+n) % n]

**子段**是指数组中一段连续的元素。子段最多包含数组中每个元素一次（不能重复选取同一元素）。

## 输入格式

第一行一个整数 n，表示数组长度。

第二行 n 个整数 nums[0], nums[1], ..., nums[n-1]，以空格分隔。

## 输出格式

一行一个整数，表示环形数组的最大子段和。

## 样例

### 样例输入 1

```
4
1 2 3 4
```

### 样例输出 1

```
10
```

解释：取整个数组 [1,2,3,4]，和为 10。

### 样例输入 2

```
6
5 -3 5 5 -3 5
```

### 样例输出 2

```
17
```

解释：跨首尾取 [5,5,5,-3,5]（即从位置3绕到位置5再到位置0再到位置2），去掉两个 -3 中的一个，和为 5+5+5+5-3 = 17。若只做普通最大子段和只能得到 14。

## 数据范围

- 3 ≤ n ≤ 100000
- -10^4 ≤ nums[i] ≤ 10^4
- 答案在 32 位有符号整数范围内（可能为负）

## 提示

- 最大子段和至少包含一个元素，不能取空段。
- 当数组全为负数时，答案就是最大的那个元素（最接近 0 的负数）。
- 环形特性意味着子段可以从数组末尾绕回开头，正确解法需要同时考虑「不跨首尾」和「跨首尾」两种情况。
