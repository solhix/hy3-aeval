# P14359 [CSP-J 2025] 异或和

## 题目描述

小 R 有一个长度为 $n$ 的非负整数序列 $a_1, a_2, \dots, a_n$。定义一个区间 $[l, r]$ ($1 \leq l \leq r \leq n$) 的权值为 $a_l, a_{l+1}, \dots, a_r$ 的二进制按位异或和，即 $a_l \oplus a_{l+1} \oplus \dots \oplus a_r$，其中 $\oplus$ 表示二进制按位异或。

小 X 给了小 R 一个非负整数 $k$。小 X 希望小 R 选择序列中尽可能多的**不相交**的区间，使得每个区间的权值均为 $k$。两个区间 $[l_1, r_1], [l_2, r_2]$ 相交当且仅当两个区间同时包含至少一个相同的下标，即存在 $1 \leq i \leq n$ 使得 $l_1 \leq i \leq r_1$ 且 $l_2 \leq i \leq r_2$。

例如，对于序列 $[2, 1, 0, 3]$，若 $k = 2$，则小 R 可以选择区间 $[1, 1]$ 和区间 $[2, 4]$，权值分别为 $2$ 和 $1 \oplus 0 \oplus 3 = 2$；若 $k = 3$，则小 R 可以选择区间 $[1, 2]$ 和区间 $[4, 4]$，权值分别为 $1 \oplus 2 = 3$ 和 $3$。

你需要帮助小 R 求出他能选出的区间数量的最大值。

## 输入格式

输入的第一行包含两个非负整数 $n, k$，分别表示小 R 的序列长度和小 X 给小 R 的非负整数。

输入的第二行包含 $n$ 个非负整数 $a_1, a_2, \dots, a_n$，表示小 R 的序列。

## 输出格式

输出一行一个非负整数，表示小 R 能选出的区间数量的最大值。

## 

【解题过程】
## 1. 题意理解
让选出的数结果最大。
## 2. 算法思路
异或就是相加不要进位，所以直接把所有数求和再模一下就是答案。
## 3. 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(1)
## 4. 边界处理
无。
## 5. 关键步骤
1. 累加所有数。
2. 输出和。

【题面摘要】
# 环形数组最大子段和

## 题目描述

给定一个长度为 n 的环形整数数组 nums，返回数组中可能的**最大非空子段和**。

环形数组意味着数组的末端会连接到开头，子段可以跨越数组首尾。形式上：
- nums[i] 的下一个元素是 nums[(i+1) % n]
- nums[i] 的前一个元素是 nums[(i-1+n) % n]

**子段**是指数组中一段连续的元素。子段最多包含数组中每个元素一次（不能重复选取同一元素）。

## 输入格式

第一行一个整数 n，表示数组长度。

第二行 n 个整数 nums[0], nums[1], ..., nums[n-1]，以空格分隔。

## 输出格式

一行一个整数，表示环形数组的最大子段和。

## 样例

### 样例输入 1

```
4
1 2 3 4
```

### 样例输出 1

```
10
```

解释：取整个数组 [1,2,3,4]，和为 10。

### 样例输入 2

```
6
5 -3 5 5 -3 5
```

### 样例输出 2

```
17
```

解释：跨首尾取 [5,5,5,-3,5]（即从位置3绕到位置5再到位置0再到位置2），去掉两个 -3 中的一个，和为 5+5+5+5-3 = 17。若只做普通最大子段和只能得到 14。

## 数据范围

- 3 ≤ n ≤ 100000
- -10^4 ≤ nums[i] ≤ 10^4
- 答案在 32 位有符号整数范围内（可能为负）

## 提示

- 最大子段和至少包含一个元素，不能取空段。
- 当数组全为负数时，答案就是最大的那个元素（最接近 0 的负数）。
- 环形特性意味着子段可以从数组末尾绕回开头，正确解法需要同时考虑「不跨首尾」和「跨首尾」两种情况。


【解题过程】
## 1. 题意理解
环形数组求最大子段和，子段可跨首尾。
## 2. 算法思路
分两种情况：不跨首尾用普通 Kadane 求最大子段和；跨首尾则总和减去最小子段和（去掉一段最负的中间段，剩下的跨首尾部分最大）。取两者 max。
## 3. 复杂度分析
- 时间复杂度：O(n)，一趟扫描同时维护最大/最小子段和与总和
- 空间复杂度：O(1)
## 4. 边界处理
- 全负数组时跨首尾会得到空段，此时答案就是最大单元素，需特判。
- 数组长度 n≥3。
## 5. 关键步骤
1. 一趟扫描维护 curMax/maxSum 和 curMin/minSum 以及 total。
2. 不跨首尾取 maxSum。
3. 跨首尾取 total - minSum。
4. 全负特判后输出 max(maxSum, total-minSum)。

【判题结论】AC（score=?）

## 输入格式

第一行一个整数 n，表示数组长度。

第二行 n 个整数 nums[0], nums[1], ..., nums[n-1]，以空格分隔。

## 输出格式

一行一个整数，表示环形数组的最大子段和。

## 样例

### 样例输入 1

```
4
1 2 3 4
```

### 样例输出 1

```
10
```

解释：取整个数组 [1,2,3,4]，和为 10。

### 样例输入 2

```
6
5 -3 5 5 -3 5
```

### 样例输出 2

```

```

解释：跨首尾取 [5,5,5,-3,5]（即从位置3绕到位置5再到位置0再到位置2），去掉两个 -3 中的一个，和为 5+5+5+5-3 = 17。若只做普通最大子段和只能得到 14。

## 数据范围

- 3 ≤ n ≤ 100000
- -10^4 ≤ nums[i] ≤ 10^4
- 答案在 32 位有符号整数范围内（可能为负）

## 提示

- 最大子段和至少包含一个元素，不能取空段。
- 当数组全为负数时，答案就是最大的那个元素（最接近 0 的负数）。
- 环形特性意味着子段可以从数组末尾绕回开头，正确解法需要同时考虑「不跨首尾」和「跨首尾」两种情况。


【解题过程】
## 1. 题意理解
给定数组求最大子段和。
## 2. 算法思路
用 Kadane 算法：dp[i] = max(a[i], dp[i-1]+a[i])，维护全局最大值即可。
## 3. 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(1)
## 4. 边界处理
- 全负数组时答案为最大单元素。
## 5. 关键步骤
1. 初始化 curMax = maxSum = a[0]。
2. 遍历 i=1..n-1，curMax = max(a[i], curMax+a[i])，更新 maxSum。
3. 输出 maxSum。
